# W1 deviations from `docs/design.md`

Workstream W1 (foundations: workspace, limits, error, runtime, sync, clock, wake, log, format, dsp,
binding glue, stubs, invariant script). Each entry gives the reason and the exact new signature.

## 1. `Carry::gen` is spelled `r#gen` (plus a `generation()` alias)

`gen` is a reserved keyword in edition 2024 (the workspace edition, §2.2), so neither a field nor a
method can be named `gen` without a raw identifier. Intent (the carry records the generation it
belongs to) is unchanged.

```rust
impl Carry {
    pub fn r#gen(&self) -> u64;          // §12.2 `gen()`
    pub fn generation(&self) -> u64;     // alias
    pub fn set(&mut self, tail: &[u8], generation: u64);   // parameter renamed from `gen`
    /// Drops the carry if it belongs to another generation (§7.3 step 2); true if bytes were dropped.
    pub fn sync_gen(&mut self, generation: u64) -> bool;   // addition
}
```

`Carry::splice` returns `false` both when nothing was carried and when carry + head is still a
partial frame; in the latter case the head bytes are appended to the carry (a write shorter than the
missing head must not lose bytes). The W4 writer must therefore not call `set()` after a `false`
splice of a non-empty carry.

## 2. `TickResampler` latency for 8 kHz → 48 kHz is 4.35 ms (not ≤ 4.3 ms)

With the §8.7 parameters (`SincFixedIn`, `Nearest`, `oversampling = L`, `sinc_len = 64·M`) rubato
keeps `sinc_len/2 + 1 + ⌈1/ratio⌉` input frames of look-ahead before its first output, and the
output FIFO needs one extra frame of slack when the position step is not a short binary fraction
(rubato's accumulator then makes the per-call count jitter by ±1). Measured `delay_frames()`:

| from → to | 8k | 16k | 24k | 48k |
|---|---|---|---|---|
| 8k  | 0 | 4.250 ms | 4.292 ms | **4.354 ms** |
| 16k | 4.000 ms | 0 | 4.125 ms | 2.167 ms |
| 24k | 4.000 ms | 4.063 ms | 0 | 1.417 ms |
| 48k | 4.000 ms | 2.000 ms | 1.333 ms | 0 |

The unit test bounds every pair by 4.3 ms except 8 kHz → 48 kHz (4.36 ms). All other §13.1
requirements hold (exact `to/50` frames per call over 180 000 ticks, passband ±0.2 dB,
aliases/images ≤ −120 dB, `reset()` == fresh, zero allocations per call).

## 3. Extra W1 files

* `crates/sbcore/src/alloc_count.rs` — the per-thread counting allocator of §13.1/§13.2
  (`CountingAlloc`, `CountGuard`, `count()`), compiled and installed as the global allocator only
  under `cfg(test)` or feature `test-hooks`. W1's zero-allocation tests need it before W5's
  `testing/` exists; `native._testing.alloc_count()` (W5) should call `sbcore::alloc_count::count()`.
* `src/py/wake.rs` — `native.WakeBell` (W1 per §12.6). W2's `Connection` takes the doorbell with
  `pub(crate) fn WakeBell::take(&self) -> Option<sbcore::wake::Doorbell>`.
* `src/py/mod.rs` declares every `src/py/*` module; non-W1 files are placeholders.

## 4. Additions beyond the §12.2 surface (no contract changes)

* `limits::RUNTIME_WORKERS: RangeInclusive<usize> = 1..=8` (used by `runtime::configure`).
* `runtime`: `RuntimeConfig: Default (2, 1)`, `is_started()`, `in_foreign_process(pid)`,
  `check_not_forked()`, and the counter statics in `runtime::live` (`CONN_SHARED`, `OWNED_DRIVER`,
  `CONN_WORKER`, `DISPATCH`, `SUB_QUEUE`, `EVENT_QUEUE`, `PCM_QUEUE`, `LIVE_READER`, `DONE_GUARD`,
  `SONGBIRD_INPUT`, `SSRC_STATE`, `TRACK_FLAGS`, `DECODE_THREAD`) for `LiveCounter::new(&live::X)`.
  `live_counts()` reports `songbird_live_tasks` as 0 until the scheduler exists (it never starts a
  runtime).
* `CloseReason::from_name(&str) -> Option<CloseReason>`, `CoreError::invalid(&'static str)`,
  `impl From<TryReserveError> for CoreError` (→ `Alloc`).
* `clock::Clock::manual() -> (Clock, Arc<ManualClock>)`, `ManualClock::now()`, `ManualClock::elapsed()`.
* `wake`: `Doorbell::from_unix_stream(UnixStream)` (cfg(unix); tests/harnesses),
  `WakeHub::creator_pid()`, `WakeToken::hub()`.
* `log`: `pub use log::{Level, LevelFilter}` (the binding has no direct `log` dependency),
  `set_level(prefix, level) -> bool` (false when the 32-slot prefix table is full) and
  `level_for(target)`. Prefixes are module-path aware (`"songbird"` matches `songbird::x`, not
  `songbirds`); the longest prefix wins; `""` sets the fallback. Defaults: `sbcore` and
  `discord_ext_songbird_native` INFO, everything else WARN. Records from `Role::Mixer` threads are
  dropped before formatting (the mixer never logs).
* `format`: `SampleRate::ALL`, `Encoding::{as_str, parse, sample_width, is_g711}`,
  `Format::{bytes_per_ms, openai_format}`, the §9.2 presets as `format::{PCM16_8K, …, GEMINI_LIVE_OUTPUT}`
  plus `format::PRESETS`; `Format::parse` also accepts preset names and the MIME types produced by
  `mime_type()`. `mime_type()` appends `;channels=2` for stereo formats (§9.2 lists mono examples
  only). `PcmBuf::{is_empty, as_i16, as_i16_mut, as_f32, as_f32_mut}`, `PcmParser::{format,
  convert_frame}`, `Carry::{new, is_empty, bytes}`.
* `dsp`: `mix::f32_sample_to_i16`, `level::LEVEL_FLOOR_DBFS` (−100 dBFS floor), `Limiter::{gain,
  reset}`, `g711::{ulaw_decode, alaw_decode, ULAW_SILENCE, ALAW_SILENCE}`,
  `b64::{try_encode_into, decoded_len_estimate, encoded_len}`, `TickResampler::{is_passthrough,
  input_len, output_len, underruns}`, `StreamResampler::expected_output_frames(in_frames)` (callers
  `try_reserve` that many frames before feeding large inputs; `process`/`flush` keep the contract's
  infallible signatures).
* `StreamResampler` removes the filter delay: output frame `k` is aligned (to the nearest frame) with
  input time `k·from/to`, and `flush()` makes the total length exactly `round(in·to/from)`.
* `TickResampler` is `Sync` (rubato's interpolator is only `Send`; it is wrapped in an `&mut`-only
  `Exclusive`), so it can live inside symphonia `Decoder` implementations (which require `Sync`).

## 5. Build profiles

`[profile.dev.package."*"] opt-level = 2` and `[profile.test] opt-level = 2` were added to the root
`Cargo.toml`: rubato/opus/symphonia are far too slow unoptimised for `maturin develop` builds, and
the §13.1 DSP tests run 180 000 ticks per rate pair. Release settings are unchanged.

## 6. Binding-side notes for W2–W5

* `supported_codecs()` is implemented in the binding (`src/lib.rs`) from the mirrored cargo
  features (`cfg!`), as in 0.5. W4 may re-point it to `sbcore::tx::source::supported_codecs()`.
* `native._shutdown_all()` currently sets `SHUTTING_DOWN` and stops logging; W2 adds the
  `REGISTRY` sweep (`close(ProcessExit)` on every live connection).
* `errors.rs` documents the constructor contract `errors.py` (W5) must accept:
  `ConnectFailed(reason, code)`, `ConnectionClosed(reason)`, `StreamClosed(reason)`,
  `StreamOverflow(reason)`, `PlaybackFull(needed_ms, free_ms)`,
  `LimitExceeded(what, value, minimum, maximum)`, and `(message,)` for the rest. The attributes are
  also set on the instance after construction. Without `discord.ext.songbird.errors` the nearest
  builtin (`ValueError` / `RuntimeError` / `TimeoutError`) is raised.
* `set_log_level(prefix, level)` takes `int | str` (`logging` levels or names; `CRITICAL`/`OFF`
  disable). `_log_wait(max, timeout_s)` returns `(python_level, rust_target, message, unix_ts)`
  with `python_level` ∈ {5, 10, 20, 30, 40}.
* `AudioFormat` accepts encoding aliases in its constructor (`pcm16`, `s16le`, `float32`, `ulaw`,
  `pcmu`, `g711_ulaw`, …) in addition to the four canonical names.

## 7. Phase-0 contract audit (verification pass)

* **`CoreError::Io` (new variant).** §11.1 requires `AudioFile.from_path` to raise `OSError` "from
  `io::Error`", but §12.2's `CoreError` had no variant that can carry an `io::Error` through
  `tx::memory::read_file(...) -> Result<Vec<u8>, CoreError>` (a `Source(String)` would become
  `SourceError`). Smallest fix: one transparent variant, deliberately without `#[from]` so no other
  I/O path is silently turned into an `OSError`:

  ```rust
  pub enum CoreError { /* … §12.2 variants … */
      #[error(transparent)] Io(std::io::Error),   // only tx::memory::read_file produces it
  }
  ```

  `src/errors.rs` maps it with pyo3's `PyErr::from(io::Error)` (`FileNotFoundError`,
  `PermissionError`, … — all `OSError` subclasses).
* **G1 letter, `WakeBell`.** The pyclass field is `bell: std::sync::Mutex<Option<Doorbell>>`, which is
  neither an `Arc`, a songbird handle nor `Copy`. The doorbell is an owned socket that
  `Connection(...)` must move out exactly once (`WakeBell::take`), so the frozen pyclass needs
  interior mutability; an `Arc<Doorbell>` would let two connections share one fd. It holds no Python
  object (I1 holds), the lock is uncontended and O(1), and nothing else can reach it.
* **`configure_runtime(net_workers, rx_workers)`** takes Python `int`s checked with
  `convert::int_arg` against `limits::RUNTIME_WORKERS` before narrowing (a negative count raises
  `LimitExceeded`, not `OverflowError`). Signature: `fn configure_runtime(py, net_workers: i64,
  rx_workers: i64) -> PyResult<()>` (stub unchanged: `int`).
