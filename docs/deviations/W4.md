# W4 deviations from `docs/design.md` (phase 0b skeleton)

Workstream W4 (send: `crates/sbcore/src/tx/*`, `src/py/{playback,sources}.rs`). Phase 0b created every
§12.5 item at its contract signature; bodies are stubs that return
`Err(CoreError::Internal("unimplemented"))` or an inert value. This file lists everything that differs
from, or adds to, the letter of §12.5 / §12.6.

## 1. `PcmProvider::on_reader_drop` (trait addition)

`LiveReader` and `PcmDecoder` hold only `Arc<dyn PcmProvider>`, but §7.4 requires their `Drop` to
store `reader_gone = true`. The trait gains a defaulted method:

```rust
pub trait PcmProvider: Send + Sync + 'static {
    // … §12.5 methods unchanged …
    /// Atomics only; called when the reader or decoder holding this provider is dropped.
    fn on_reader_drop(&self) {}
}
```

`PcmQueue` implements it by storing `st.reader_gone`; memory sources keep the default.

## 2. Lint allowances (phase 0 only)

Skeleton modules start with `#![allow(dead_code, unused_variables)] // phase-0 skeleton` (only the
parts that need it).

## 3. Bodies that are already real

* `PlaybackSpec::validate` (ranges + `prebuffer_ms`, `max_gap_ms` ≤ `max_buffer_ms/2`),
  `validate_opus_packet` (1..=1275 bytes, 960 samples at 48 kHz), `SourceSpec::{kind, seekable}`,
  `supported_codecs()` (the cfg table; `native.supported_codecs()` now calls it, as W1's note invited).
* `TrackControl for TrackHandle` (errors ignored), `FakeTrackControl` (test-hooks).
* `LiveReader::next_packet` (empty 960-frame packet, EOF iff `should_end()`), `seek` no-op,
  `into_inner`; `PcmDecoder::decode` returns one tick of silence. Neither is constructed yet
  (`live_pcm_input` is a stub).
* `PcmQueue::{set_volume, volume, is_closed, wake_id, attach_track}`, `LiveSource::close` sets the
  end flag; `Housekeeper::{add, link, close_all}`; `OpusQueue::close`.

## 4. Additions and shape choices (no contract signature changed)

* Internal helper modules (all `pub(crate)`): `writer.rs` (`ParsedWrite`, `parse_write(parser,
  data, carry_len, cap_bytes)`), `anchor.rs` (`Anchor`, `GapReject`, `GapDecision`, `decide(...)`),
  `tags.rs` (`TagId`, `TagEntry`, `TagTable`, `RejectSet`). `PcmQueue::write` stays in `queue.rs`.
* `PcmQueue` private fields beyond §7.2: `clock: Clock` (`new` takes it), `QueueAtomics::clears`,
  `QueueInner::end_waiting` (for `arm_end`). `END_DRAIN/END_ABORT/END_POISON/END_CONN_CLOSED` are
  `pub(crate)` constants. `PlaybackLimits`, `Seg`, `Prebuffer`, `QueueInner`, `QueueAtomics` are
  `pub(crate)`.
* `ClearOpts: Default` (`reject_late=True`, `hold_ms=0`, no gap window); `WriteMeta: Default`;
  derives (`Clone, Copy, Debug, PartialEq` …) on the plain data types.
* `opus_stream`: `pub const MAX_OPUS_PACKET: usize = 1275`. `OpusQueue::new(spec, token, send_muted)`
  has no id parameter (unlike `PcmQueue::new`); resolved in §6 below (`tx::next_source_id()`).
* `encoded`: `pub static ENCODED_WORKERS: AtomicUsize` (§3.1) lives in `tx/encoded.rs`.
* `memory`: `EncodedBytes::{is_empty, data}`, `MemPcm::format`, `OpusFrames::{is_empty,
  duration_ms}` (clippy `len_without_is_empty`; getters of the pyclasses). `OpusFrames.offsets` holds
  `len() + 1` entries (packet `i` is `bytes[offsets[i]..offsets[i+1]]`).
* `FakeTrackControl::{new(flags), log(), LOG_CAP = 4096}` (the test-only call log is bounded).

## 5. Binding (`src/py/{playback,sources}.rs`)

* `Playback.write(data, tag=None, at_ms=None) -> None` and `write_base64(data: str | bytes, …)`.
  `close(drain=False)`. The `volume` setter takes the value as an object (stub type `float`) and
  extracts it, because pyo3-stub-gen 0.23.1 cannot generate a setter that also takes `Python<'_>`.
* `EncodedSink` (§12.6 lists no members): `write(data)`, `arm_space(nbytes)`, `finish()`,
  `close(drain=False)`, `wake_id`, `track`. `OpusSink`: `send(packet)`, `arm_space()`, `clear()`,
  `buffered_ms`, `close(drain=False)`, `wake_id`, `track`. Both (and `Playback`) are `weakref` and close
  with `Abort` on drop.
* `ClearResult.items` is a `tuple[ItemProgress, ...]`; `ItemProgress` holds `Arc<ItemProgressData>`
  (its `tag` is an `Arc<str>`); `ClearResult` holds `Arc<ClearSummary>`; `PlaybackStats` holds the
  `Copy` `PlaybackStatsData` (`skip_from_py_object`).
* Sources: `AudioFile(data)`, `AudioFile.from_path(path, *, max_bytes=256 MiB)` (read + probe under
  `py.detach`), `AudioFile.from_arrow(array)`; `RawPcm(data, format: AudioFormat | str)` rejects `str`
  data with `InvalidAudio` and parses detached above 1 MiB; `RawPcm.from_samples(data, sample_rate,
  channels=2, encoding="f32le")` treats a non-buffer object with `__arrow_c_array__` as Arrow input;
  `OpusPackets(iterable)` copies each packet and enforces `MAX_OPUS_PACKETS` / `MAX_SOURCE_BYTES`
  while iterating (`LimitExceeded`). `AudioFile.load` is async and therefore belongs to the Python
  layer (W5).

## 6. Phase-0 contract audit (verification pass)

* **Live-source ids (resolves the §4 open question).** §12.5 gives `PcmQueue::new(id, …)` an id but
  `OpusQueue::new(spec, token, send_muted)` and `spawn_encoded(spec, token, done)` none, although
  both types implement `LiveSource::id()` (and `spawn_encoded` must build an internal `PcmQueue`).
  Instead of changing those signatures (and `SourceSpec::to_input`, which calls `spawn_encoded`),
  every live-source id comes from one process-wide counter:

  ```rust
  // tx/mod.rs
  pub fn next_source_id() -> u32;   // AtomicU32, starts at 1, never returns 0
  ```

  `ConnShared::open_playback` passes `next_source_id()` to `PcmQueue::new`; `OpusQueue::new` and
  `spawn_encoded` (for its internal `PcmQueue`, whose id `EncodedShared::id()` reports) call it
  themselves. Ids are therefore unique per process, which also keeps `playback_id` unambiguous in
  `VoiceEvent.Playback*`.
* **`read_file` I/O errors are `CoreError::Io`** (new W1 variant, see `w1.md` §7), so
  `AudioFile.from_path` raises `OSError` subclasses as §11.1 requires; a file over `max_bytes` is
  `CoreError::Limit`.
* **Numeric arguments checked before narrowing** (`LimitExceeded`, not `OverflowError`):
  `AudioFile.from_path(path, *, max_bytes: i64)` → `1..=MAX_SOURCE_BYTES`;
  `RawPcm.from_samples(data, sample_rate: i64, channels: i64 = 2, …)` → `SOURCE_RATE_HZ` and `1..=2`
  (stub types unchanged: `int`).
* **G1 letter / §4.3.** `Playback`, `EncodedSink` and `OpusSink` hold, besides their `Arc<PcmQueue>` /
  `Arc<EncodedShared>` / `Arc<OpusQueue>`, a `track: TrackRef` (two `Arc`s) and a `conn:
  Weak<ConnShared>` — the same pair §4.3 lists for `NativeTrack` — because §12.6 gives them a `track`
  member that returns a `NativeTrack`. §4.3's row for `Playback` lists only `q`. No Python object is
  held (I1).
