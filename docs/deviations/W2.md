# W2 deviations from `docs/design.md` (phase 0b skeleton)

Workstream W2 (events, ctrl, conn, tracks, and the binding files `src/py/{connection,events,tracks}.rs`).
Phase 0b created every §12.3 item at its contract signature; bodies are stubs that return
`Err(CoreError::Internal("unimplemented"))` or an inert value. This file lists everything that differs
from, or adds to, the letter of §12.3 / §12.6, with the reason. The test-hook skeleton (§13.2, W5 files)
was also created in phase 0b and is recorded at the end.

## 1. Lint allowances (phase 0 only)

* Skeleton modules start with `#![allow(dead_code, unused_variables)] // phase-0 skeleton`; modules
  whose stubs take `&mut Vec<_>` out-parameters without pushing also allow `clippy::ptr_arg` (the
  contract signatures keep `&mut Vec`). Remove these when the bodies are written.
* `ConnWorker::run` keeps the contract signature `pub fn run(self) -> impl Future<Output = ()> + Send`
  with `#[allow(clippy::manual_async_fn)]`: the explicit `+ Send` bound is part of the API, which an
  `async fn` cannot state.

## 2. Bodies that are already real (small, fully specified)

* `VoiceSettings::validate` (ranges of §9.3, unit conversion). A duration that is not a multiple of
  20 ms is reported as `CoreError::InvalidAudio` (a `ValueError` in Python) because `CoreError` has no
  generic invalid-argument variant; ranges are `CoreError::Limit` (`LimitExceeded`).
* `normalize_endpoint`, `GatewayState::{new, status, next_deadline, next_action_seq}` (`step` is a
  no-op), `KindMask::of`.
* `build_config` and every `OwnedDriver` method (thin songbird wrappers under `runtime::net().enter()`,
  exactly §4.8 / §4.7 T2–T4).
* `Dispatch::act` (`catch_unwind` + panic counter; `on_event` is a no-op), `TrackFlags::{resolve, hint,
  ended, uuid}`, `DoneGuard` drop hint, `TrackRegistry::{register, bind}`, `conn::registry` functions.
* `ConnShared::close` performs T0 and the T9 registry removal only.

## 3. Placement and additions (no contract signature changed)

* `registry_snapshot()` / `shutdown_all(reason)` live in `conn/registry.rs` (a §12.1 W2 file) and are
  re-exported from `conn::shared` and `conn`. `register` / `unregister` are `pub(crate)`.
  `native._shutdown_all()` (W1's `src/lib.rs`) now calls `sbcore::conn::shutdown_all(ProcessExit)`.
* `conn::settings`: the per-field ranges are `pub const`s in `settings.rs` (`DECODE_STATE_TIMEOUT_S`,
  `SPEAKING_HANGOVER_MS`, `VOICE_THRESHOLD_DBFS`, `MAX_DECODED_USERS`, `MAX_RECEIVE_MB`,
  `STALL_TIMEOUT_MS`, `BITRATE_BPS: RangeInclusive<i64>`, `DRIVER_TIMEOUT_S`, `DRIVER_RETRIES`,
  `REJOIN_ATTEMPTS`) rather than in W1's `limits.rs`. `RawVoiceSettings: Default` (the §9.3 defaults);
  `RawVoiceSettings`/`VoiceSettings` derive `Clone, Copy, Debug, PartialEq` (the `VoiceSettings`
  pyclass holds `Copy` data, G1). `ConnParams: Clone, Debug`.
* `events`: `EVENT_KINDS = 13`, `KindMask::matches(ev)`; bit `i` of a `KindMask` is the `i`-th
  `EventData` variant in declaration order (`Connected` = bit 0 … `Lagged` = bit 12).
  `KindMask`/`Pop`/`EventHub`/`EventQueue` also derive `Debug` (+ `PartialEq, Eq` for `KindMask`).
* `ctrl::Control` derives `PartialEq, Eq`.
* `gateway`: `Phase::state_name()`, `GatewayParams::new(guild, user, reconnect, rejoin_attempts,
  auto_recover)` (the documented 5/3/15/5/5 s durations); `StatusSnapshot` additionally derives `Copy`
  (and `Debug, PartialEq, Eq`); `Phase`, `DiscKind`, `DiscReason`, `ConnectFailure`, `GwInput`,
  `GwAction`, `ActionBatch` derive `Clone`/`Debug` as applicable.
* `dispatch`: `pub(crate) fn Dispatch::new(conn: Weak<ConnShared>, rx: Option<RxSender>,
  tracks: Weak<TrackRegistry>, ctrl_overflow: Arc<Mutex<VecDeque<RxInput>>>) -> Dispatch`,
  `Dispatch::{heartbeat, counters}`; `DispatchCounters { panics, ticks_dropped, ctrl_dropped,
  heartbeat }`.
* `worker`: `WorkerShared::new(budget_max: usize) -> Arc<Self>`, `WorkerShared::{budget_used,
  is_shutdown}`, `BudgetGuard::bytes()`, `pub(crate) fn ConnWorker::new(conn, shared, pipeline, rx_in,
  overflow, clock) -> ConnWorker`. `BudgetGuard::drop` already releases its bytes.
* `ops`: `OpRegistry::new()` (+ `Default`); `TrackInfoData: Clone, Copy, Debug, PartialEq`;
  `OpResult: Debug`.
* `shared`: `pub fn ConnShared::tracks(&self) -> &TrackRegistry` — the binding needs the registry to
  call the contract's `TrackQueue::enqueue(src, opts, reg)`. Private fields beyond §12.3:
  `reconnect`, `receive`, `unclassified: Arc<Mutex<Vec<u64>>>` (handed to `RxPipeline::new`),
  `stats: ConnStats`, a `LiveCounter`.
* `tracks`:
  * `pub const DROPPED, EOF_SEEN, DECODE_ERROR: u8` (hint bits); `TrackEndReason::as_str`,
    `TrackKind::{as_str, is_live}`.
  * `pub fn TrackFlags::new(id: u64, kind: TrackKind, conn_closing: Arc<AtomicBool>) -> Self`,
    `TrackFlags::{hints, error}`, `pub(crate) fn set_uuid`.
  * `DoneGuard` keeps the contract shape `DoneGuard(Arc<TrackFlags>)` (`pub(crate) fn new`,
    `pub fn flags`) and maintains `live::DONE_GUARD` by hand instead of holding a `LiveCounter`.
  * `PlayOpts: Default` (volume 1.0, loops `Some(0)`, not paused).
  * `pub fn TrackRegistry::new(conn_closing: Arc<AtomicBool>) -> Self`.
  * `TrackQueue::{new, is_empty}` (clippy `len_without_is_empty`) and
    `pub fn TrackQueue::remove(&self, t: &TrackRef) -> bool` — §7.10 says `stop()` on a pending entry
    removes it, but `PendingChange` has no stop and `dequeue(index)` would race with other writers.
    The queue state is three L10 leaf locks/atomics (`items`, `current`, `paused`).
  * `pub fn tracks::flags::set_track_loops(h: &TrackHandle, loops: Option<u32>) -> Result<(),
    CoreError>`: `TrackHandle::loop_for` takes `nonmax::NonMaxU32`, which the binding cannot name
    (no `nonmax` dependency, §2.3).
  * `pub use songbird::tracks::{ControlError, TrackHandle}` from `sbcore::tracks`: the binding crate
    has no direct songbird dependency (§2.3) but its pyclasses use songbird handles.

## 4. Binding surface (`src/py/{connection,events,tracks}.rs`)

* Python class names follow §12.6; the Rust struct of `VoiceSettings` is `PyVoiceSettings`
  (`name = "VoiceSettings"`) to avoid clashing with `sbcore::conn::VoiceSettings`.
* `VoiceSettings(*, receive=True, playout_buffer_ms=60, …)` is keyword-only with the §9.3 defaults.
  Integer arguments are taken as Python `int` (`i64`) and checked against their range **before**
  narrowing (`crate::convert::int_arg`, added to W1's `src/convert.rs`), so negative or huge values
  raise `LimitExceeded` (a `ValueError`), never `OverflowError`. The same helper is used by every
  numeric argument of `Connection`, `Playback` and the test hooks. `mix_mode` other than
  `"mono"`/`"stereo"` raises `ValueError`. Getter added: `VoiceSettings.receive`.
* `Connection` method defaults mirror §9.4 (`chunk_ms=20`, `max_queue_ms=2000`,
  `overflow="drop_oldest"`, `max_buffer_ms=60000`, …); `subscribe_events(max_queue=256,
  kind_mask=0x1FFF)`; `play/enqueue(source, volume=1.0, loops=0, paused=False)`;
  `enqueue_stream(volume=1.0, loops=0, paused=False, max_buffer_bytes=1 << 20)`;
  `start_track_info(track, timeout_ms)`, `start_track_seek(track, seconds, timeout_ms)` (seconds
  checked against `SEEK_S`); `close(reason="closed")` raises `ValueError` for an unknown reason name.
  Ids of 0 raise `ValueError` before the `WakeBell` is taken, so the bell keeps owning its fd.
  `take_controls()` takes no argument and drains every slot (`ConnShared::take_controls(usize::MAX)`).
  The `source` parameter is typed `AudioFile | RawPcm | OpusPackets` in the stubs.
* `Control.ClassifyUsers` is the empty struct variant `ClassifyUsers()`: pyo3 complex enums do not
  support unit variants.
* `Control.Closed.reason`, `VoiceEvent.{Disconnected, PlaybackEnded, TrackEnded}.reason` are owned
  `String`s: pyo3 complex-enum variant constructors require `FromPyObject` fields, which
  `&'static str` is not. They are Rust data, not Python objects, so I1 holds; strictly this is the
  only pyclass data that is neither `Arc<sbcore::…>`, a songbird handle nor `Copy` (G1 letter).
  `VoiceEvent.SpeakingStarted.captured_at` is a `float` (`time.monotonic()`, via
  `crate::py::chunk::monotonic`).
* pyo3 0.29 deprecates the implicit `FromPyObject` of `Clone` pyclasses: `VoiceSettings` is
  `from_py_object` (it is extracted by value in `Connection(...)`); `ConnectionStatus`, `Control`,
  `VoiceEvent`, `TrackInfo` are `skip_from_py_object`.
* `NativeTrack`: `pending` is "no songbird handle yet and not ended"; `pause/resume/set_volume/
  set_loops` go to the handle, or to `TrackQueue::update_pending` for a pending entry; `stop()` on a
  pending entry calls `TrackQueue::remove`; `set_loops` on a live source raises `TrackError`;
  `__eq__`/`__hash__` use the identity of the shared `TrackFlags`; `uuid` is the hyphenated form of
  `TrackHandle::uuid().as_u128()`.

## 5. Test-hook skeleton (W5 files `crates/sbcore/src/testing/*`, `src/py/testing.rs`)

* `native._testing` is a declarative submodule (`#[pymodule(submodule, name = "_testing",
  gil_used = false)]`) registered only under `test-hooks`; classes use
  `module = "discord.ext.songbird.native._testing"`; no stubs are generated (§12.6 Stubs rules).
* `detached_connection(guild_id, user_id, settings, bell=None) -> (Connection, Harness)`: an optional
  `bell` was added (§12.6 lists no doorbell argument); `None` means the harness creates its own
  doorbell and tests poll `take_ready()` directly. sbcore entry point:
  `pub fn testing::Harness::detached(guild_id: NonZeroU64, user_id: NonZeroU64,
  settings: VoiceSettings, bell: Option<Doorbell>) -> Result<(Arc<ConnShared>, Harness), CoreError>`
  (it will build on `ConnShared::new_detached`); `Harness::step(&self, advance_ms: u64) ->
  Result<(), CoreError>`, `Harness::clock()`.
* `inject_driver_event(conn, kind, reason=None, code=None, ssrc=0)`: `kind` is `"connect"`,
  `"reconnect"`, `"disconnect"` (= runtime) or `"disconnect:connect|reconnect|runtime"`; `reason` is
  a `DiscReason` name (`"ws_closed"` uses `code`); `ssrc` was added for connect/reconnect. sbcore:
  `pub enum testing::DriverEvent { Connect { ssrc }, Reconnect { ssrc }, Disconnect { kind, reason } }`,
  `inject_driver_event(conn: &ConnShared, ev: DriverEvent)`.
* The injection functions take owned `Vec<u8>` payloads (`inject_tick(conn, voices: Vec<(u32,
  Option<Vec<u8>>)>, silent: Vec<u32>)`, `inject_voice_tick_rtp(conn, packets: Vec<(u32, Vec<u8>)>)`)
  because the binding has no `bytes` dependency.
* `testing::MixerHarness::take(playback: &Arc<PcmQueue>) -> Result<Arc<Self>, CoreError>` and
  `pull(&self, ticks: usize, out: &mut Vec<f32>)` (interior `Mutex`, so the pyclass holds only an
  `Arc`); Python `MixerHarness(playback).pull(ticks)` returns little-endian `f32` bytes.
* `testing::{track_log(&TrackRef) -> Vec<&'static str>, alloc_count() -> u64}`, `testing::rtp::{RtpOpts,
  encode_opus, rtp_wrap}` (both return `Result` so they can be stubs).

## 6. Phase-0 contract audit (verification pass)

* **`EventSubscription` has no `hub: Weak<EventHub>`.** §4.3 lists `queue: Arc<EventQueue>, hub:
  Weak<EventHub>`, but the §12.3 facade gives the binding no way to obtain the hub
  (`ConnShared.events` is private; `subscribe_events` returns only the queue). The pyclass holds
  `queue: Arc<EventQueue>` only; `close()`/`Drop` call `EventQueue::close()`. Implementation note for
  W2: `EventHub` must prune closed queues itself (on `emit` and `subscribe`) so a closed
  subscription's `Arc<EventQueue>` does not stay in the hub until connection close.
* **Numeric arguments now checked before narrowing** (`LimitExceeded`, never `OverflowError`),
  completing §4 "Binding surface" above:
  * `subscribe_mixed(…, floor_release_ms: i64)` → `0..=u32::MAX` (no tighter bound exists in §9.5);
  * `subscribe_events(max_queue, kind_mask: i64)` → `kind_mask ∈ 0..=0x1FFF` (`KindMask::ALL`);
  * `start_track_info(track, timeout_ms: i64)`, `start_track_seek(track, seconds, timeout_ms: i64)` →
    `timeout_ms ∈ 0..=u64::MAX`;
  * `queue_dequeue(i: i64)`: a negative index raises `IndexError` like any other out-of-range index
    (§9.8 `TrackQueue.dequeue`), instead of `OverflowError`.
