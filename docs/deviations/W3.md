# W3 deviations from `docs/design.md`

Workstream W3 (receive: `crates/sbcore/src/rx/*`, `src/py/{receive,chunk,arrow}.rs`). Everything in
§8 / §12.4 / §12.6 (W3 rows) is implemented. This file lists what differs from, or adds to, the letter
of the contract, with the reason. No contract signature was changed.

## 0. Integration notes for W2 (must-read when wiring `ConnShared`/`ConnWorker`)

* **`RxPipeline::attach_worker(&mut self, worker: Weak<WorkerShared>)` (addition).** The
  `listen_users` router creates per-user subscriptions inside the pipeline (§8.9), which needs the
  `WorkerShared` for `reserve_budget` (budget check), `register_queue` (T6) and the `RemoveSub` path
  of `Subscription::close`. `RxPipeline::new`'s fixed signature has no such parameter, so the
  ConnWorker (or `ConnShared::new`) must call `pipeline.attach_worker(Arc::downgrade(&shared))` once.
  Without it (a pipeline driven on its own, e.g. the unit tests) router streams are created
  unbudgeted and detached (`Subscription::detached`); the pipeline still unregisters them when their
  queue closes.
* **Router-created `SubId`s** have bit 63 set (`pipeline::ROUTER_SUB_ID_BIT`), so they never collide
  with the connection's own monotonic ids (`ConnShared::subscribe` must keep its ids below 2⁶³).
* **`apply()` queues; commands take effect at the next `on_input`/`on_timer`.** `RxPipeline::apply`
  has no `now`, but subscribing must fast-forward an idle (lazy) timeline to `expected(now) − 2`
  (§8.8) before the lane is created. Commands are therefore applied in order at the start of the next
  `on_input`/`on_timer` ("at the next lane boundary", §4.9). `ConnWorker::step` already runs timers
  every iteration.
* **`ConnShared::subscribe`** should: `spec.validate()?`, check `MAX_SUBS_PER_CONN`,
  `reserve_budget(spec.budget_bytes()?)`, `SubQueue::new(&spec, token)`, `register_queue`, push
  `RxCmd::AddSub`, and return `Subscription::new(id, queue, Arc::downgrade(&worker), guard)`.
  `RouterSpec::validate()` exists for `subscribe_router` (each routed stream is budget-checked when
  it is created, `RouterSpec::stream_budget_bytes`).
* **T6** closes registered queues with `SubQueue::close(ConnectionClosed)`: queued chunks stay
  readable until drained (§9.5). `Subscription::close()` (Python `close()`/drop) uses
  `SubQueue::close_and_clear`, which frees queued chunks immediately (§9.5 "frees queued chunks",
  §10 R9 "close/Drop (freed immediately)").
* **Watchdog.** `RxTimer::stalled_since` is `Some` on **every** `on_timer` call while the stall lasts
  (the gateway rate-limits `RxStalled` and needs repeated inputs to see the 5 s mark); the
  `ReceiveStalled` event itself is emitted once per stall by the pipeline.
* **Panic containment** (§5.7, ConnWorker): on a caught tick panic call
  `pipeline.close_all(CloseReason::InternalError)`; it closes every queue (pending `AddSub`s
  included) and drops all consumer state but keeps the SSRC → user map.
* `ConnShared::timeline_ms()` can mirror `RxPipeline::timeline_ms()` into an atomic after each step.

## 1. `TickMeta` (referenced but not defined by §12.4)

`Lane::feed(&mut self, tick: u64, converted: &[f32], meta: &TickMeta, out: &mut Vec<Arc<ChunkData>>)`
names a `TickMeta` type that §12.4 never defines. It is defined in `rx/lane.rs`:

```rust
#[derive(Clone, Debug)]
pub struct TickMeta {
    pub voiced: bool,                      // → voiced_ms, speaking
    pub concealed: bool,                   // → concealed_ms
    pub synthetic: bool,                   // → gap_ms
    pub speakers: SmallVec<[u64; 8]>,      // → speakers (union over the chunk, sorted)
    pub captured_at: Instant,              // → captured_at (first tick of the chunk)
}
```

`user_id` comes from the lane's `SourceKey`, `timeline_ms` from the chunk's first sample, `level`
(RMS dBFS, peak) from the f32 samples before encoding. Ticks split by a chunk boundary (10/30 ms
chunks) contribute their per-frame share to `voiced_ms`/`concealed_ms`/`gap_ms`.

## 2. Receive core (`crates/sbcore/src/rx`)

* **`opus.rs`**: `pub fn extract(pkt, payload_offset, payload_end) -> Option<Extracted>` with
  `Extracted { range, seq: u16, dave_stripped: bool }`; `extract_opus` (verbatim §8.3) is a wrapper.
  The pipeline needs the RTP sequence number (decoder reset on jumps) and the
  `dave_trailers_stripped` counter without parsing twice.
* **`decoder.rs`**: constants `DECODE_SCRATCH_LEN` (5 760 × 2), `MAX_ERRORS_IN_ROW` (5),
  `MAX_SEQ_JUMP` (10); a jump of more than 10 in **either** direction (wrapping `i16` distance)
  resets. Accessors `carry_frames`, `user`/`set_user`, `last_seen_tick`/`touch`,
  `take_overflow_frames`. The carry keeps `(frames, concealed)` runs so `TickFill` is exact. A loss is
  concealed only when the carry holds less than one tick (a 40/60/120 ms packet still covers it).
* **`speaking.rs`**: `end_tick(tick, out)` (addition) advances every speaking user that got no
  `on_tick` this tick (silence, synthetic ticks, users absent from the `VoiceTick`), so hangovers run
  without packets. `user_left` emits `SpeakingStopped` (if speaking) **and** `UserLeft` (§13.1 "emits
  Stopped then Left"). `SpeakingStopped.timeline_ms` is the end of the last voiced tick and
  `duration_ms` the spurt length (bridged concealment included); the hangover is not part of it.
  `is_speaking`, `speaking_users`. Only speaking users are stored (bounded map).
* **`bus.rs`**: `MixFilter::{everyone, selects, takes_unmapped}`, `MixBus::{filter, floor_holder}`.
  Floor ties (equal RMS) go to the lower user id (determinism). Floor buses never mix unmapped audio
  (it has no user to hold the floor). `UserFrames.unmapped` is mixed only by `mix` buses with
  `include is None`.
* **`convert.rs`**: `Converter::{output_len, rate, channels, delay_frames}`.
* **`lane.rs`**:
  * Lanes do not hold their subscribers (the §12.4 comment lists `subs` inside `Lane`): the pipeline
    keeps `subscription → lane` and fans out each lane's chunks. That is what makes `set_filter`
    re-homing gap- and duplicate-free: the old lane delivers chunks starting before the switch
    boundary, the new one from it, and both can be fed in the same tick.
  * `Lane::covering(key, fmt, chunk_ms, tick)` (addition): the first chunk is the one containing
    `tick`, its earlier part digital silence (`0xFF`/`0xD5` for G.711). Router streams use it so a
    user's first voiced tick is never cut off by a long `chunk_ms`; all other lanes start at the next
    aligned boundary (§8.7).
  * A tick gap (only after a >60 s outage, see §3) drops the partial chunk and realigns; older ticks
    are ignored. The next chunk buffer is allocated right after an emission (`try_reserve`); an
    allocation failure drops that one chunk (`alloc_failures`).
  * Accessors: `key, format, chunk_ms, chunk_bytes, next_chunk_start_ms, chunks, alloc_failures,
    realigns`.
* **`queue.rs`**:
  * The budget reservation moves **into the queue** (`Subscription::new` calls
    `SubQueue::attach_budget`) and is released as soon as the queue is closed **and empty** (explicit
    close/drop, T6 + drained, overflow + drained). §8.9 says the budget is released "at the same time"
    as unregistration; releasing it while closed chunks are still queued would let Σ queued bytes
    exceed `max_receive_mb`. `Subscription` therefore holds `{id, queue, worker, removed}` (no
    `budget` field); `Subscription::detached(id, queue)` is `pub(crate)`.
  * Pop protocol: queued items, then `Closed(Overflow)` exactly once, then `Closed(Closed)`;
    `close_reason()` stays `Overflow`. `drain(max, out)` reports a close reason only when it moved
    nothing (so an overflow report is never swallowed by a non-empty batch).
  * `close` wakes an armed consumer (a `close()` from a foreign thread wakes the loop waiter).
    `close_and_clear` (addition) also frees the queued chunks.
  * `drop_oldest` with `max_chunks == 1` carries the evicted audio to the incoming chunk.
  * Additions: `SubSpec::max_chunks`, `CHUNK_META_BUDGET_BYTES` (160), `SubQueue::{max_chunks,
    queued_chunks (lock-free), queued_bytes (diagnostics), close_and_clear}`;
    `stats().queued_ms = queued_chunks × chunk_ms` (O(1)).
  * `Subscription::set_filter` errors: per-user stream → `InvalidAudio` (a `ValueError`); closed →
    `StreamClosed(reason)`; worker gone → `StreamClosed(ConnectionClosed)`.
* **`router.rs`**: `RouterSpec::{validate, stream_budget_bytes, selects, sub_spec}`;
  `RouterQueue::{is_closed, pending}` and `pub(crate) {push, count_dropped, alloc_token}`. The router
  remembers (weakly) every stream it created so `close(close_streams=true)` can close streams Python
  already received; pending, never-received streams are closed by any `close`. `dropped` also counts
  streams that could not be created (budget, subscription cap, wake ids). A user gets one stream per
  presence: `close_on_leave` closes it with `"user_left"` and the user gets a new stream when they
  speak again; a stream closed by the consumer is not recreated.
* **`pipeline.rs`**:
  * Constants: `SYNTH_TRIGGER_TICKS` (5), `SYNTH_SLACK_TICKS` (2), `DEBT_TICKS` (5),
    `MAX_SYNTH_BURST` (3 000 ticks = 60 s, the largest queue bound): a longer outage synthesises the
    last 60 s and fast-forwards the rest (lanes realign; stream clocks jump) instead of running
    millions of ticks at once on the RX worker. `USER_LEFT_PRUNE` (1 s), `MAX_SSRC_MAPPINGS` (1 024,
    least recently seen evicted), `ROUTER_SUB_ID_BIT`.
  * `RxCounts` gains `converters`, `buses`, `router_streams`. `ticks_real` counts processed real
    ticks; skipped ones are only in `ticks_skipped`.
  * `ReceiveStalled.since_ms` is the receive-timeline position (ms since `t0`) at which the stall
    began (last real tick or link-up).
  * Decoding is needed for a user with a per-user lane, a bus that selects them, a router that
    selects them, or whenever `voice_threshold_dbfs` is set; unmapped SSRCs only for a `mix` bus with
    `include is None`. Speaking state always uses packet presence.
  * A `Map` for a user cancels a pending `UserLeft` prune of that user (rejoin within 1 s).
* **`test_util.rs`, `pipeline_tests.rs`** (new private `cfg(test)` modules): RTP/Opus builders,
  fixed-seed xorshift, wake hubs; the synchronous pipeline tests of §13.1 (synthesis from `t0`,
  100 ms trigger, burst/debt, decode-on-demand, `set_filter` re-homing, watchdog, resource release,
  overflow policies, every format, router, pruning, threshold, floor, 1-hour soak within budget).

## 3. Binding (`src/py/{receive,chunk,arrow}.rs`)

* `ReceiveSubscription` holds an `sbcore::rx::Subscription` and `RouterSubscription` an
  `sbcore::rx::RouterHandle` directly (as §4.3 lists), i.e. structs of `Arc`/`Weak`/atomics.
* `ReceiveSubscription` additions: `format`, `user_id`, `chunk_ms` getters (router-created streams
  need them). `set_filter(include, exclude, ignore_bots=True, policy="mix", floor_release_ms=600)`;
  `read_batch(max_chunks=50)` takes a Python `int` checked against `1..=6000` (`LimitExceeded`, never
  `OverflowError`) and raises `StreamOverflow` once under `overflow="error"`, like `try_recv`.
* `AudioChunk` is `#[pyclass(frozen, weakref)]`: the §13.4 leak test takes `weakref.ref` of chunks
  (§5.6 lists `weakref` only for `Connection`, `ReceiveSubscription`, `Playback`).
* `AudioChunk.__getbuffer__`: with `PyBUF_FORMAT` the view is typed (`'h'`/`'f'`/`'B'`, itemsize
  2/4/1); otherwise a plain byte view (itemsize 1, no format), as `PyBuffer_FillInfo` does.
  `shape`/`strides` live in a small box in `view.internal`, freed by `__releasebuffer__`;
  `view.obj = self`. A `compile_error!` rejects big-endian targets.
* `captured_at`: the `(Instant, time.monotonic())` anchor is captured on first use in a
  `PyOnceLock<(Instant, f64)>` (plain data) rather than at module init (W1's `lib.rs`); equivalent.
* Arrow (`arrow` feature): `AudioChunk.__arrow_c_array__` exports `Int16`/`Float32`/`UInt8` arrays
  over the chunk's own buffer via `Buffer::from_custom_allocation(ptr, len, Arc<ChunkData>)` with
  field metadata `{sample_rate, channels, encoding}`; `ChunkBatch` holds `Arc<Vec<Delivered>>` (sbcore
  data) and builds the `StructArray` at export (`pcm` concatenated in one `try_reserve` copy; >2 GiB
  rejected); `__arrow_c_schema__` exports the batch `Schema` (a struct); `to_pyarrow()` is
  `pyarrow.record_batch(self)`; `__repr__` added. Without the feature every member raises
  `SongbirdError("built without the 'arrow' feature")`. `export_chunk` returns `PyResult` (internal).
* Arrow import helpers for W4 (`import_bytes`, `import_samples -> (SampleKind, Vec<u8>)`,
  `import_binary`) copy into Rust memory with `try_reserve`, check `MAX_SOURCE_BYTES` /
  `MAX_OPUS_PACKETS` before allocating, respect slice offsets, reject nulls, and drop the imported
  array while attached. Errors are `InvalidAudio` (a `ValueError`).
* `py-src/discord/ext/songbird/native/__init__.pyi` was regenerated with `cargo run --bin stub_gen`
  (only the W3 docstrings / `ChunkBatch.__repr__` changed).

## 4. Verification

* `cargo test -p sbcore` (+ `--features test-hooks`): 64 receive tests, including the 10⁶-packet
  `extract_opus` fuzz and the 180 000-tick soak.
* The binding was exercised from CPython 3.14t (GIL disabled) against a locally built extension with
  temporary (uncommitted) constructors: buffer protocol for all four encodings (`memoryview` format
  and itemsize, `np.frombuffer` sharing memory, read-only), `to_base64() ==
  base64.b64encode(bytes(c))`, a memoryview pins the chunk, an Arrow export outlives the chunk object,
  pyarrow 26 and arro3 0.9.1 round-trips of `AudioChunk` and `ChunkBatch`, field metadata, and all
  three import helpers (UInt8/Binary/LargeBinary/Int16/Float32, sliced arrays, null and type errors).
