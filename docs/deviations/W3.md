# W3 deviations from `docs/design.md` (phase 0b skeleton)

Workstream W3 (receive: `crates/sbcore/src/rx/*`, `src/py/{receive,chunk,arrow}.rs`). Phase 0b created
every §12.4 item at its contract signature; bodies are stubs that return
`Err(CoreError::Internal("unimplemented"))` or an inert value. This file lists everything that differs
from, or adds to, the letter of §12.4 / §12.6.

## 1. `TickMeta` (referenced but not defined by §12.4)

`Lane::feed(&mut self, tick: u64, converted: &[f32], meta: &TickMeta, out: &mut Vec<Arc<ChunkData>>)`
names a `TickMeta` type that §12.4 never defines. It is defined in `rx/lane.rs` with the per-tick
facts a lane folds into `ChunkMeta`:

```rust
#[derive(Clone, Debug)]
pub struct TickMeta {
    pub voiced: bool,                      // → voiced_ms, speaking
    pub concealed: bool,                   // → concealed_ms
    pub synthetic: bool,                   // → gap_ms
    pub speakers: SmallVec<[u64; 8]>,      // → speakers
    pub captured_at: Instant,              // → captured_at (first tick of the chunk)
}
```

`user_id` comes from the lane's `SourceKey`, `timeline_ms` from `tick`, `level` from the samples.

## 2. Lint allowances (phase 0 only)

* Skeleton modules start with `#![allow(dead_code, unused_variables)] // phase-0 skeleton`
  (+ `clippy::ptr_arg` where a stub takes an unused `&mut Vec` out-parameter).
* `RxInput` and `RxCmd` carry `#[allow(clippy::large_enum_variant)]`: `RxInput::Tick(RawTick)` is
  ~0.5 KB inline by design (boxing would allocate once per tick on the NET runtime); `RxCmd::AddSub`
  is likewise kept inline.

## 3. Bodies that are already real

* `RawTick::from_voice_tick` (copies `(ssrc, Bytes, offsets)` handles; `payload_end` =
  `payload_end_pad`, an end index, §8.3).
* `extract_opus` (verbatim §8.3) and `is_silent_frame`; `pub const SILENT_FRAME: [u8; 3]`.
* Accessors: `SubQueue::{stats, wake_id, origin_timeline_ms, close, is_closed}`,
  `RouterQueue::{dropped, wake_id, close}`, `RxPipeline::{timeline_ms, counts}`. `SubQueue::close`
  records the first reason; `Subscription::close`/`Drop` close the queue and push `RemoveSub`.
* `MixBus::new` builds the −1 dBFS / 80 ms `Limiter` (mix is a stub that outputs silence).

## 4. Additions (no contract signature changed)

* `RxCmd` is defined in `rx/queue.rs`.
* `SubQueue::{format, user_id, chunk_ms, close_reason}` accessors (the binding needs them; the router
  creates subscriptions whose user and format Python must learn).
* `pub(crate) fn Subscription::new(id, queue, worker: Weak<WorkerShared>, budget: BudgetGuard)`;
  `pub fn RouterQueue::new(token: WakeToken) -> Arc<Self>`; `ChunkData::duration_ms()`.
* `RxCounts` fields: `ticks_real, ticks_synthetic, ticks_skipped, bad_packets, decode_errors,
  plc_frames, carry_overflow_frames, dave_trailers_stripped, decoders_active, subscriptions, routers,
  lanes` (`Clone, Copy, Default`). `RxConfig: Clone, Copy, Debug`; `RxTimer: Default`.
* Derives: `RawVoice`/`RawTick`/`RxInput: Clone, Debug`; `Overflow: Debug, PartialEq, Eq`;
  `RxSource: Clone, Debug, PartialEq, Eq`; `SubSpec`/`RouterSpec: Clone, Debug`;
  `Delivered: Clone, Debug`; `SubStats: Clone, Copy, Debug, Default, PartialEq, Eq`;
  `TickFill: Clone, Copy, Debug, Default, PartialEq, Eq`; `BusActivity: Default`.
* Pop protocol as the binding implements it: `Pop::Closed(CloseReason::Overflow)` → `StreamOverflow`;
  any other `Pop::Closed(r)` → `StreamClosed(r)`. W3 must therefore return `Closed(Overflow)` exactly
  once and a different reason (e.g. `Closed`) afterwards (§8.9 "raises `StreamOverflow` once").

## 5. Binding (`src/py/{receive,chunk,arrow}.rs`)

* `ReceiveSubscription` holds an `sbcore::rx::Subscription` and `RouterSubscription` an
  `sbcore::rx::RouterHandle` directly (as §4.3 lists), i.e. structs of `Arc`/`Weak`/`BudgetGuard`,
  not a bare `Arc`.
* `ReceiveSubscription` additions: `format`, `user_id`, `chunk_ms` getters (router-created streams
  need them for the Python `AudioStream`). `set_filter(include, exclude, ignore_bots=True,
  policy="mix", floor_release_ms=600)` — §12.6 gives no parameter list; it raises `ValueError` on a
  per-user stream. `skip_to_live(reset_clock=True)`, `read_batch(max_chunks=50)`.
* `AudioChunk.__getbuffer__`: when the consumer requests `PyBUF_FORMAT` the view is typed (`'h'`/`'f'`/
  `'B'`, itemsize 2/4/1); otherwise it is a plain byte view (itemsize 1, no format), as
  `PyBuffer_FillInfo` does. `shape`/`strides` live in a small box in `view.internal`, freed by
  `__releasebuffer__`; `view.obj = self`. A `compile_error!` rejects big-endian targets. The buffer
  path cannot be exercised yet (no chunk can be produced in phase 0).
* `captured_at`: the `(Instant, time.monotonic())` anchor is captured on first use in a
  `PyOnceLock<(Instant, f64)>` (plain data) rather than at module init (W1's `lib.rs`); equivalent.
* `ChunkBatch` holds `Arc<Vec<Delivered>>` (sbcore data) and will build the Arrow `StructArray` at
  export, so the pyclass never holds arrow-rs objects; `__len__` added. Its Arrow members (and
  `AudioChunk.__arrow_c_array__`) return `CoreError::FeatureMissing("arrow")` without the feature and
  `Internal("unimplemented")` with it until implemented.
* The Arrow import helpers used by W4's sources (`import_bytes`, `import_samples -> (SampleKind,
  Vec<u8>)`, `import_binary`) and `export_chunk` live in `src/py/arrow.rs`.

## 6. Phase-0 contract audit (verification pass)

* **§4.3 vs §12.4, `Subscription`.** §4.3 describes `Subscription{queue: Arc<SubQueue>, worker:
  Weak<WorkerShared>, token: WakeToken}`; the §12.4 contract is `Subscription{id, queue, worker,
  budget: BudgetGuard}` with the wake token owned by the queue (`SubQueue::new(spec, token)`). The
  code follows §12.4 (the token must live with the queue the worker rings).
* **`ChunkData: Send + Sync + RefUnwindSafe`** (§12.4) is now a compile-time assertion in
  `rx/chunk.rs`, so a future field cannot silently break the Arrow `Allocation` requirement.
* **`ReceiveSubscription.set_filter(…, floor_release_ms: i64)`** is checked against `0..=u32::MAX`
  with `convert::int_arg` (negative → `LimitExceeded`, not `OverflowError`), like
  `Connection.subscribe_mixed`.
